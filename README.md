# Аккорды из Яндекс.Музыки

Сайт показывает ваши плейлисты из Яндекс.Музыки и подбирает к песням гитарные аккорды.

## Что нужно один раз

1. Python 3.11 или новее: <https://www.python.org/downloads/>. На Windows при установке поставьте галочку «Add Python to PATH».
2. Токен Яндекс.Музыки (инструкция ниже).

## Как получить токен

Токен выдаётся через вход по Яндекс ID:

1. В браузере, где вы вошли в Яндекс, откройте ссылку
   <https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d>
   (это официальная страница Яндекс ID для приложения Яндекс.Музыки).
2. Нажмите «Войти как …» / «Разрешить».
3. Яндекс перекинет на адрес вида `https://music.yandex.ru/#access_token=y0_...&token_type=bearer...`.
   Скопируйте всё между `access_token=` и следующим `&` — это токен.

Если страница Музыки сразу перезагрузилась и токен пропал из адреса: откройте DevTools (F12) → Network,
включите **Preserve log** и откройте ссылку ещё раз — адрес с токеном останется в списке запросов.

Токен даёт доступ к вашему аккаунту, никому его не отправляйте. Когда он истечёт, сайт покажет «Токен истёк» — получите новый так же.

## Запуск на компьютере

В папке проекта скопируйте `.env.example` в файл `.env` и впишите токен в `YANDEX_MUSIC_TOKEN=`.

Затем в терминале (на Windows — PowerShell), находясь в папке проекта:

```bash
python -m venv venv
source venv/bin/activate        # Mac / Linux
# venv\Scripts\activate         # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Откройте <http://localhost:8000>.

**С телефона дома:** запустите командой `uvicorn app.main:app --host 0.0.0.0` и откройте на телефоне `http://<адрес компьютера в Wi-Fi>:8000`. Телефон и компьютер должны быть в одной сети.

## Сайт в интернете (Render)

Чтобы сайт открывался откуда угодно, его можно выложить на Render.com: настройки уже лежат в `render.yaml`. В настройках Render нужно указать:

- `YANDEX_MUSIC_TOKEN` — токен;
- `APP_PASSWORD` — пароль на вход, чтобы чужие не видели ваши плейлисты.

Бесплатный тариф Render «засыпает» без посетителей, поэтому первое открытие после перерыва может занять около минуты.

## Откуда берутся аккорды

Сайт ищет песню по очереди на AmDm.ru, MyChords.net и Ultimate-Guitar.com и показывает первый найденный вариант
со ссылкой на источник. Страницы этих сайтов нигде не сохраняются. Если сайт поменяет вёрстку или не пустит сервер,
на странице песни будет видно, какой сайт что ответил, а подробности — в логах Render.
