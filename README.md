# Аккорды из Яндекс.Музыки

Сайт показывает ваши плейлисты из Яндекс.Музыки и подбирает к песням гитарные аккорды.

## Что нужно один раз

1. Python 3.11 или новее: <https://www.python.org/downloads/>. На Windows при установке поставьте галочку «Add Python to PATH».
2. Токен Яндекс.Музыки (инструкция ниже).

## Как получить токен

Токен выдаётся через вход по Яндекс ID:

1. В браузере, где вы вошли в Яндекс, откройте ссылку
   <https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d>
   (это официальная страница Яндекс ID для приложения Яндекс.Музыки).
2. Нажмите «Войти как …» / «Разрешить».
3. Яндекс перекинет на адрес вида `https://music.yandex.ru/#access_token=y0_...&token_type=bearer...`.
   Скопируйте всё между `access_token=` и следующим `&` — это токен.

Если страница Музыки сразу перезагрузилась и токен пропал из адреса: откройте DevTools (F12) → Network,
включите **Preserve log** и откройте ссылку ещё раз — адрес с токеном останется в списке запросов.

Токен даёт доступ к вашему аккаунту, никому его не отправляйте. Когда он истечёт, сайт покажет «Токен истёк» — получите новый так же.

## Запуск на компьютере

В папке проекта скопируйте `.env.example` в файл `.env` и впишите токен в `YANDEX_MUSIC_TOKEN=`.

Затем в терминале (на Windows — PowerShell), находясь в папке проекта:

```bash
python -m venv venv
source venv/bin/activate        # Mac / Linux
# venv\Scripts\activate         # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Откройте <http://localhost:8000>.

**С телефона дома:** запустите командой `uvicorn app.main:app --host 0.0.0.0` и откройте на телефоне `http://<адрес компьютера в Wi-Fi>:8000`. Телефон и компьютер должны быть в одной сети.

## Сайт в интернете (Render)

Чтобы сайт открывался откуда угодно, его можно выложить на Render.com: настройки уже лежат в `render.yaml`. В настройках Render нужно указать:

- `YANDEX_MUSIC_TOKEN` — токен;
- `APP_PASSWORD` — пароль на вход, чтобы чужие не видели ваши плейлисты (или вход через Яндекс ID, см. ниже).

Бесплатный тариф Render «засыпает» без посетителей, поэтому первое открытие после перерыва может занять около минуты.

## Вход для друзей (Яндекс ID)

Вместо общего пароля можно пускать на сайт друзей по их аккаунту Яндекса. Сайт узнаёт только логин человека,
его пароль от Яндекса сайт не видит. Пока Яндекс ID не настроен, работает старый пароль `APP_PASSWORD`.

**1. Зарегистрируйте приложение в Яндекс ID** (один раз, бесплатно):

1. Откройте <https://oauth.yandex.ru/client/new> под своим аккаунтом Яндекса.
2. Название — например, «Аккорды». Платформа — «Веб-сервисы».
3. В поле **Redirect URI** впишите адрес сайта и `/auth/yandex/callback`, например
   `https://yachords.onrender.com/auth/yandex/callback` (адрес сайта виден вверху страницы сервиса на Render).
   Для запуска на компьютере можно добавить второй адрес: `http://localhost:8000/auth/yandex/callback`.
4. В разделе доступов выберите только **«Доступ к логину, имени и фамилии, полу»** (`login:info`). Больше ничего не нужно.
5. Сохраните. Яндекс покажет **ClientID** и **Client secret** — они понадобятся на следующем шаге.

Вид страницы Яндекса может немного отличаться, но эти поля там есть всегда.

**2. Впишите настройки на Render** (сервис yachords → Environment):

| Настройка | Что вписать |
|---|---|
| `YANDEX_ID_CLIENT_ID` | ClientID приложения |
| `YANDEX_ID_CLIENT_SECRET` | Client secret приложения (никому не показывайте) |
| `OWNER_LOGIN` | ваш логин в Яндексе: именно вам сайт показывает плейлисты по `YANDEX_MUSIC_TOKEN` |
| `ALLOWED_LOGINS` | логины друзей через запятую, например `boris, vera.ivanova` |

После сохранения сайт перезапустится, и на странице входа появится кнопка «Войти через Яндекс ID».
`APP_PASSWORD` после этого можно удалить. Чтобы закрыть другу доступ, уберите его логин из `ALLOWED_LOGINS`.

**3. Друзья подключают свою Яндекс.Музыку.** После первого входа друг попадает на страницу «Моя Яндекс.Музыка»
с пошаговой инструкцией: открыть страницу Яндекса, скопировать адрес из адресной строки и вставить его на сайт.
Удобнее делать это с компьютера; телефон потом подключается по QR-коду с той же страницы.
Ваши плейлисты друзьям не показываются никогда.

Токен друга хранится только в его браузере, в зашифрованной cookie, привязанной к его логину. Ключ шифрования
выводится из `YANDEX_ID_CLIENT_SECRET` (или задаётся отдельно в `MUSIC_COOKIE_KEY`). Если сменить секрет,
всем придётся подключить Музыку заново.

Вы тоже можете подключить свою Музыку на этой странице (ссылка «Моя Яндекс.Музыка» внизу главной).
Тогда `YANDEX_MUSIC_TOKEN` в настройках Render станет не нужен.

## Откуда берутся аккорды

Сайт ищет песню по очереди на AmDm.ru, MyChords.net и Ultimate-Guitar.com и показывает первый найденный вариант
со ссылкой на источник. Страницы этих сайтов нигде не сохраняются. Если сайт поменяет вёрстку или не пустит сервер,
на странице песни будет видно, какой сайт что ответил, а подробности — в логах Render.

Песня ищется по названию и исполнителю: одноимённые песни других групп пропускаются, а исполнитель,
записанный латиницей («Kino») или кириллицей («Кино»), считается одним и тем же.

Если сайт нашёл не те аккорды или не нашёл ничего, под аккордами есть поле «Не те аккорды? Вставьте свою ссылку».
Туда можно вставить ссылку на страницу песни на AmDm.ru, MyChords.net или Ultimate-Guitar.com. Ссылка запоминается
в браузере для этой песни, поэтому на телефоне и компьютере её нужно вставить отдельно. Кнопка
«Вернуть автоматический поиск» её забывает.

## Если что-то пошло не так

| Что видно на сайте | Что делать |
|---|---|
| «Токен истёк» | Получить новый токен (раздел выше) и заменить `YANDEX_MUSIC_TOKEN` на Render. На странице ошибки есть та же инструкция и кнопка. |
| «Яндекс.Музыка не отвечает» | Подождать минуту и обновить страницу. |
| «Аккорды не найдены» | Песни нет на сайтах с аккордами. Можно открыть перебор на примере или поискать на AmDm вручную. |
| «Сайты с аккордами не ответили» | Сайты временно недоступны или не пускают сервер. Попробовать позже; если повторяется часто — посмотреть логи Render. |
| «Это инструментальный трек» | В треке нет слов, поэтому сразу показан перебор. |
| Сайт долго открывается первый раз | Бесплатный Render засыпает без посещений и просыпается около минуты. |
